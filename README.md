# Basic Employee Onboarding (AD)(RBAC)

## Problem Statement
Northstar Medical Group is a growing fictional healthcare organization that has relied on a Managed Service Provider (MSP) for IT support for several years, resulting in poorly managed infrastructure and a lack of standardized IT practices. User accounts, access permissions, and administrative processes are inconsistent and lack centralized management, creating operational inefficiencies and potential security vulnerabilities. Manual processes and the absence of clearly defined policies and procedures increase the risk of unauthorized access, inconsistent access control, and inadequate auditing. These deficiencies also introduce potential HIPAA compliance risks, particularly regarding the protection of sensitive patient information. I was brought on to design and implement a structured IT infrastructure using Active Directory to centralize identity management, standardize access controls, and establish a stronger security foundation.
